# 已有功能变更

分析变更影响，同步规格并形成增量任务。

| 项目 | 说明 |
| --- | --- |
| Skill 名称 | feature-evolution |
| 适用时机 | 已有需求或实现需要补充、调整或扩展 |
| 主要产出 | 更新后的规格及 CR 变更任务 |

## 使用示例

> 给已有评论功能增加回复能力，梳理这次变更

## 文件说明

- [SKILL.md](SKILL.md)：AI 使用的完整技能定义。
- [assets/](assets/)：技能随附的资源，请与技能一起复制。

## 安装

将整个 feature-evolution/ 文件夹复制到所用 AI 工具的技能目录，保留内部资源。Codex 通常使用 ~/.codex/skills/，安装后按工具要求刷新或重启会话。

这些技能依赖目标项目自身的规范和上下文；使用前请阅读 [仓库使用说明](../README.md#使用与安装)。
