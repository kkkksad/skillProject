## 文件说明

## 安装

将整个 project-tech-stack/ 文件夹复制到所用 AI 工具的技能目录，保留内部资源。Codex 通常使用 ~/.codex/skills/，安装后按工具要求刷新或重启会话。

这些技能依赖目标项目自身的规范和上下文；使用前请阅读 [仓库使用说明](../README.md#使用与安装)。
