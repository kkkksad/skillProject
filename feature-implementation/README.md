| 项目 | 说明 |
| --- | --- |

| 主要产出 | 功能代码与验证证据；普通和重大变更附阶段记录 |

## 文件说明

- [SKILL.md](SKILL.md)：AI 使用的完整技能定义。
- [assets/](assets/)：技能随附的资源，请与技能一起复制。

## 安装

将整个 feature-implementation/ 文件夹复制到所用 AI 工具的技能目录，保留内部资源。Codex 通常使用 ~/.codex/skills/，安装后按工具要求刷新或重启会话。

这些技能依赖目标项目自身的规范和上下文；使用前请阅读 [仓库使用说明](../README.md#使用与安装)。
