# 功能编码实现

把已明确的需求实现并验证，保留 AC → 任务 → 测试的追溯关系。实现规模由当前任务决定。

## 上下文和执行模式

先读目标项目 `AGENTS.md`、相关工程配置、现有代码及规格。可选的 `specs/PROJECT-CONTEXT.md` 缺失时，直接利用已有信息建立上下文，不要求全量读取历史文档。

`specs/`、`docs/` 相对于目标项目；`assets/` 相对于本 skill。已有项目沿用其文档路径并记录映射。

| 模式 | 适用条件 | 必要输入与记录 |
| --- | --- | --- |
| 轻量修改 | 局部、需求明确、低风险，不改变权限、数据结构或外部契约 | 用户已给出的行为和验收要求、相关代码即可；在回复或已有记录中说明范围及验证，不强制新建三份文档或完成报告 |
| 普通功能 | 多文件行为变化或独立用户流程 | 需求/AC、设计和任务都应清楚，可复用已有 issue、合并规格或 `specs/features/{功能名}.md`、`{功能名}_技术方案.md`、`{功能名}_任务规划.md` |
| 重大变更 | 跨模块架构、迁移、权限、兼容性或重要外部依赖变化 | 明确影响、验收、风险、回滚和执行计划；只对未获授权的关键决策请求确认 |

增量变更读取相关 `{功能名}_变更任务_{CR序号}.md`（如有）。缺少某个文件名不等于缺少需求；先从现有文档、代码和用户确认中补齐必要信息。代码反映当前行为，不能替代用户期望。

用户指定某阶段时只执行该阶段；明确要求完成整个功能时按依赖推进所有必要阶段。已确认的范围和方案持续有效。

## 开始前

1. 确认目标行为、验收方式、影响文件和依赖状态；勾选状态需要与实际实现和验证证据一致。
2. 检查测试、浏览器、数据库及任务追踪工具实际可用情况，选择匹配技术栈的办法。
3. 有任务工具时用当前环境提供的接口；没有时使用已有计划的 Markdown 清单。不要求特定的 `TaskCreate` / `TaskUpdate`。

## 实现与测试

对新增或改变的逻辑、数据行为，默认采用 RED → GREEN → REFACTOR：

- **RED**：先为目标行为编写能暴露缺口的测试，运行并确认因预期行为尚未满足而失败。已有正确场景可以通过，回归测试应保持原有基线；不要求所有测试同时失败。语法或环境错误不是有效的 RED 证据。
- **GREEN**：做满足当前行为所需的最小实现，复用已有代码，运行目标测试与受影响的回归测试。
- **REFACTOR**：在测试保护下改善结构，保持已确认行为，按改动范围重跑必要检查。

若测试本身错误、契约已经获得批准变更，允许修正测试并解释依据；不能删除关键断言或把期望改成错误实现的结果。测试已通过时先判断行为是否已有实现，不为制造 RED 人为破坏正确代码。

纯文案、简单样式或生成配置等低风险改动，采用与风险相称的浏览器、构建或配置验证，不为满足 TDD 仪式增加无意义单测。

## 验收与完成证据

| 变化类型 | 验证方式 |
| --- | --- |
| UI、交互、样式 | 在实际页面运行 AC 对应路径；可用 Playwright MCP、Playwright CLI 或其他可用浏览器工具，必要时留截图 |
| 纯计算或无外部依赖的工具函数 | 单元测试可以作为验收证据，覆盖关键正常、边界和异常行为 |
| HTTP/API、认证、异步任务或外部集成 | 增加对应接口或集成验证，检查路由、权限和实际契约；mock 单测不能证明真实链路通过 |
| 数据库结构或持久化 | 使用匹配项目的客户端、ORM 集成测试或可用 MCP；验证迁移、约束和数据状态，不限定 Supabase，也不默认写入生产库 |

缺少首选工具时使用等价替代。无法运行关键验证时，记录原因、影响和可执行的后续步骤，将任务标为未验证或受阻，不能勾选完成或编造验收结果。

验证失败时定位原因后修复，重跑相关回归与验收；连续 3 次修复仍未通过时报告失败、证据与已尝试方案，不盲目重复。

## 收尾

1. 对照本次 AC 和任务核实完成范围，记录验证命令、结果及未覆盖项。
2. 仅将实现和必要验收都通过的任务标记 `[x]`，有未验证项的阶段保持未完成。
3. 文档出现偏差时判断原因：实现违背已确认需求则修代码；需求经批准改变或事实性说明过期才同步文档，不能通过改文档掩盖缺陷。
4. 普通功能和重大变更使用 `assets/stage-completion-report-template.md` 记录阶段结果，保存到 `docs/开发记录/{功能名}_{CR序号_如有}阶段{N}_完成报告.md`；同一报告追加验证记录，避免覆盖历史。
5. 汇报改动、验证及限制。仅在用户授权范围内提交、推送或发布。
