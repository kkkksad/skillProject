# 发布与交付验收

核对环境、配置、构建产物与数据库迁移，执行已授权发布，并在目标环境验证真实业务路径及恢复条件。

## 使用示例

> 使用 $project-release 为当前版本做发布准备，检查配置、迁移和恢复方案，先交付审查结果。

> 使用 $project-release 将当前功能部署到已配置的测试环境，验证登录、提交与刷新后的数据结果，并记录版本和访问地址。

## 文件与安装

- [SKILL.md](SKILL.md)：准备、部署、验收与恢复流程。
- [发布记录模板](assets/release-record-template.md)：保留实际证据及未验证项。

将完整 `project-release/` 目录复制到技能目录，保留资源。Codex 通常使用 `~/.codex/skills/`。

只做发布准备时不执行部署；明确要求部署时在授权范围内完成。未验证的目标环境不能标为发布成功。
