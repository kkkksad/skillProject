| 项目 | 说明 |
| --- | --- |

## 脚本验证

从本技能目录执行 `python -m unittest discover -s tests -v`。测试覆盖中文任务命名、文件名冲突、重复运行及已有内容保留，生成文件仅位于临时目录。

## 安装

将整个 doc-first-development/ 文件夹复制到所用 AI 工具的技能目录，保留内部资源。Codex 通常使用 ~/.codex/skills/，安装后按工具要求刷新或重启会话。

这些技能依赖目标项目自身的规范和上下文；使用前请阅读 [仓库使用说明](../README.md#使用与安装)。
