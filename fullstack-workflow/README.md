# 全栈项目流程

完整项目的统一入口，根据当前进度串联需求、设计、开发、验证与发布，不要求每次重走全部步骤。

## 使用示例

> 用 $fullstack-workflow 帮我从零完成一个预约管理系统。先明确核心范围，按现有团队熟悉的技术开发，做到本地可以运行并验收。

> 用 $fullstack-workflow 接手当前项目，先检查已有实现和验证缺口，完成评论列表，并部署到已配置的测试环境。

## 安装与职责

将完整目录和所需阶段技能一并复制到技能目录，保留资源。Codex 通常使用 `~/.codex/skills/`；未安装的阶段技能按等价流程执行，不假定依赖已存在。

- [SKILL.md](SKILL.md)：阶段路由与交付规则。
- [总览](../README.md)：技能目录与使用顺序。

本技能决定从哪里开始、做到哪里结束；单项任务直接使用对应阶段技能。它不自动授权提交、推送或部署。
