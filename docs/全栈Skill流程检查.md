# 全栈 Skill 流程检查

检查范围：本仓库技能、模板及随附流程说明。通用流程保留原有阶段划分，只补统一入口和发布闭环，不预设技术栈。

## 调整与职责

| 发现的问题 | 调整后规则 | 主要位置 |
| --- | --- | --- |
| 单项技能齐全，但缺少完整项目的调度入口 | 按项目状态和用户交付目标选择阶段，已有方案直接复用 | [fullstack-workflow](../fullstack-workflow/SKILL.md) |
| 编码结束后缺少发布准备及目标环境验收 | 核实版本、配置、迁移、恢复和发布后业务冒烟；准备与部署分开 | [project-release](../project-release/SKILL.md) |
| 新依赖一律确认，规范模板甚至默认禁止 | 普通兼容依赖按任务需要评估；涉及未授权重大代价再确认 | [技术设计](../feature-tech-design/SKILL.md)、[开发规范](../project-dev-standards/SKILL.md)及模板 |
| 用户操作顺序被当成开发依赖 | 以实际契约、数据和代码前置条件判断；已有数据的列表可以独立交付 | [任务拆解](../feature-task-planning/SKILL.md)及模板 |
| 技术设计偏重 API/数据库，UI 状态易在 AC 之前遗漏 | 按需设计页面状态、字段映射、刷新、无障碍与服务端授权 | [需求澄清](../feature-requirements-clarification/SKILL.md)、[技术设计](../feature-tech-design/SKILL.md)及模板 |
| 全栈验收缺少明确的串联检查 | 验证页面到真实服务与持久化、重读结果及适用的拒绝访问/失败路径 | [功能实现](../feature-implementation/SKILL.md) |
| 固定尝试次数可能导致过早收尾 | 无新证据时换诊断方法；能继续调查则推进，真实外部阻塞才报告受阻 | [功能实现](../feature-implementation/SKILL.md) |
| 偶发问题无法重现时只能停住 | 可用日志、快照与代码路径组成根因证据，保留未复现限制 | [Bug 修复](../bugfix-workflow/SKILL.md) |
| 通用规范夹带旧运行时、JSON 配置和唯一样式偏好 | 核实当前工具格式与版本，沿用实际语言、锁文件及样式共存边界 | [开发规范](../project-dev-standards/SKILL.md)、[技术栈](../project-tech-stack/SKILL.md)及模板 |

## 推荐的完整路径

新项目：需求 → 产品概述 → 技术栈 → 结构/规范 → 路线图 → 初始化 → 按功能做需求/设计/任务/实现与真实联调 → 按约定做发布准备或部署验收。

已有项目：先查现状和证据，直接从缺失环节进入。局部明确的小改动直接实现与验证；缺陷走修复；既有行为迭代走增量变更。不为流程完整而补无关文档或不存在的架构层。

每次交接保留范围、决策、实际文档路径、AC、验证证据和未决项，使用现有记录即可。doc-first-development 维护文档导航和状态，阶段技能维护规格内容，避免两套事实来源。Steiner Archive 是专用扩展，不参与普通全栈项目的必经步骤。

## 与其他技能共存

安装了 Superpowers 等流程技能时，需求讨论、计划、TDD、调试和审查复用已有产出，按任务需要组合，不重复启动整条链。前端设计、特定框架、数据库或云平台技能属于按需补充，不强制安装；缺少专用技能时用可用工具完成等价工作。

当前无需再独立新增通用安全、数据库或测试技能：它们的必要约束已分布在需求、设计、任务、实现和发布阶段。只有后续项目反复出现同一类复杂操作，才值得抽取专门技能和脚本。

## 检查边界

格式、资源路径与脚本回归属于静态/工具验证；虚拟项目请求的独立推演用于检查路由、范围和决策，不代表已经运行真实应用。第一次在实际项目使用时，应保留页面、接口、数据库和发布证据，再根据真实问题做窄幅修订。

本次检查结果：

- 17 个技能通过 skill-creator 的 `quick_validate.py`；目录名与 frontmatter 名称一致，现有 UI 元数据可解析。
- 109 个本地 Markdown 链接及 13 个正文内资源引用可解析。检查排除了历史版本介绍和代码围栏中的目标项目示例路径。
- 文档骨架脚本的 9 项现有回归测试通过，未修改脚本实现。
- 独立只读推演覆盖已有数据的列表开发、仅交付技术方案、实现后部署到已授权测试环境、仅做发布准备四种请求；对发现的终点和迁移环境措辞歧义已修订并复核。

这里只维护当前仓库，安装目录中的其他技能副本需在实际安装时使用这些版本。
